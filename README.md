# SkyScore – Flight Difficulty Analytics Platform

## 🚀 Project Overview

**SkyScore** is a data-driven platform built for United Airlines during **SkyHack 3.0**.
It introduces the **Flight Difficulty Score (FDS) and post-analysis operational insights** to quantify flight complexity and help optimize resources, reduce delays, and enhance passenger experience.

---

## ⚙️ How to Run the Project

1. Install **Jupyter Notebook** on your desktop.
2. Clone this repository:

   ```bash
   git clone https://github.com/coderiders22/Init-to-win-it
   ```
3. Open **Project.ipynb** in Jupyter Notebook.
4. Run all cells to process the datasets.
5. Final results will be saved in **test_inittogetit.csv**.

## ✨ Key Features

* **Flight Difficulty Score**: Quantifies complexity based on multiple parameters.
* **Classification**: Easy, Medium, Difficult ranking of flights.
* **Insights**: Identifies consistent problem flights, bottlenecks, and drivers.
* **Recommendations**: Staffing, baggage handling, SSR planning, scheduling buffers.
